# images folder

Put approved photos here.

- **lr-logo.png**: the official Lenoir-Rhyne logo from the university Brand Toolkit.
  The header shows it automatically. Use the white/reversed version, because the header is red.
- Player headshots, coach photos, team photos: upload here, then point to them in content.js,
  e.g. photo: "images/david-gee.jpg"
