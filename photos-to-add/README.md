# Drop roster photos here

1. Click **Add file → Upload files** in this folder.
2. Upload photos named after the person, for example `Eve Neild.jpg` or `chris jones.png`.
   Any order of first/last name works, and JPG, PNG, WEBP and iPhone HEIC are all fine.
3. Click **Commit changes**.

About a minute later the photo is cropped to a portrait, resized, renamed and moved into
`images/`, and it appears on the website. Check the **Actions** tab to see what was added.
Photos whose names don't match a player or coach stay here, and the Actions summary says why.

Use only photos the program has permission to publish.
